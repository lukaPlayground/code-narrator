# 비전공코드

코드를 몰라도 괜찮아요. AI가 쉬운 말로 단계별로 설명해줍니다.

---

## 어떤 도구인가요?

개발을 배우는 중이거나, 다른 사람이 짠 코드를 읽어야 할 때 막막한 분들을 위해 만들었어요.
코드를 선택하고 우클릭 한 번이면, AI가 비전공자도 이해할 수 있는 말로 설명해줍니다.

---

## 사용 방법

### 1. 파일 전체 설명
에디터에서 우클릭 → **비전공코드: 이 파일 설명해줘**

### 2. 선택한 코드만 설명
설명받고 싶은 코드를 드래그 → 우클릭 → **비전공코드: 선택한 코드 설명해줘**

---

## 처음 실행 시 — API 키 설정

이 확장은 **Groq**의 AI를 사용해요. **무료**로 사용할 수 있어요.

1. 확장을 처음 실행하면 아래 안내창이 뜹니다

   > "비전공코드를 사용하려면 Groq API 키가 필요해요"

2. **키 발급받기 (브라우저 열기)** 클릭

3. [console.groq.com/keys](https://console.groq.com/keys) 에서:
   - 구글 계정으로 로그인
   - **Create API key** 클릭
   - 키 이름 입력 후 생성 (`gsk_` 로 시작하는 키가 나와요)
   - 키 복사

4. VS Code로 돌아와 입력창에 붙여넣기

5. **완료!** 이후부터는 키 입력 없이 바로 사용 가능해요

---

## 이런 분께 추천해요

- 개발을 이제 막 시작한 분
- 비전공자인데 코드를 읽어야 하는 상황이 생긴 분
- 팀원이 짠 코드를 빠르게 파악하고 싶은 분
- 오픈소스 코드가 어떻게 동작하는지 궁금한 분

JavaScript, TypeScript, Python, Go, Java, C, C++, PHP, Rust, Ruby

## 개인 정보

- 입력한 코드는 Groq API로만 전송됩니다
- 별도로 수집하거나 저장하지 않아요
- API 키는 VS Code 로컬 설정에만 저장됩니다
